# Avatares do MVP

Sprites armazenados localmente para que o seletor de avatares funcione sem baixar imagens durante o uso.

- Pokémon: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon (25, 6, 133, 94, 150 e 448).
- Treinadores, líderes, campeões e vilões: https://play.pokemonshowdown.com/sprites/trainers/ (red, misty, brock, cynthia, lance, giovanni, cyrus e ghetsis).

Personagens e imagens Pokémon pertencem aos respectivos titulares. Uso neste projeto educacional independente, sem afiliação oficial.
